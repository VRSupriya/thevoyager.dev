Two of today's stories are about how much work an agent really has to do live: one attacker borrowed a trusted name, one retailer stopped asking a model for what it already knew.

## 🔥 A tampered "Claude Code" extension sat on Cursor's marketplace for about 11 hours
On 29 October Cursor found a modified copy of Anthropic's Claude Code extension on its marketplace, live between about 2:27am and 1:35pm PT. Cursor says Anthropic didn't develop it, and Anthropic told Microsoft the same. Microsoft's analysis says the code adds an SSH key labelled `svc-telemetry`, tries to open a reverse tunnel, and collects the names of environment variables that look like keys, tokens or secrets.

Cursor says permission errors blocked the SSH step on most macOS and Windows machines, but Microsoft notes files may still have been written. Cursor warns that "uninstalling the extension may not be sufficient". Neither post says how the attacker got in.

If developer machines hold cloud credentials, pin extension publishers and add an install delay.

**Affected:** `anthropic.claude-code` 2.1.312 and 2.1.313, Windows and macOS builds · **Fixed in:** Cursor removed the version, rotated keys and rebuilt the marketplace; no fixed version number stated by Cursor · **Severity:** no formal rating · **Stopgap:** search `authorized_keys` for `svc-telemetry`, hunt for connections to 134.209.82.225 · **If compromised:** isolate the host, remove the key and persistence, consider rebuilding it, and rotate credentials from a clean machine; Cursor provides macOS and Windows remediation scripts
[Source](https://cursor.com/blog/claude-code-extension-security-notice) · [Microsoft analysis](https://www.microsoft.com/en-us/security/blog/2026/10/30/inside-malicious-claude-code-branded-cursor-extension-persistent-ssh-backdoor/)

## 🚀 OpenAI's GPT-5.6 models arrive on Amazon Bedrock in GovCloud
AWS says Bedrock now serves OpenAI's GPT-5.6 family, "Terra and Luna", in the two GovCloud (US) regions, through the Responses, Converse and Chat Completions APIs. Cross-Region Inference routes requests between the two regions, and usage appears in Cost Explorer.

A second AWS notice adds Daybreak Red, "GPT-5.6 Cyber", for eligible customers in GovCloud (US-East) and US East (Ohio). Access needs enrollment in Daybreak access from OpenAI, and AWS says inference data isn't used for training. Neither notice gives prices.

For regulated US teams, this means the model call can stay behind the IAM, logging and region controls you already run in GovCloud, instead of going out to a separate vendor endpoint.

[Source](https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-openai-runtime-govcloud/) · [Daybreak Red notice](https://aws.amazon.com/about-aws/whats-new/2026/10/openai-daybreak-red-govcloud-east/)

## 🤖 LangChain's managed agents get their own browser and async subagents
Managed Deep Agents v0.10, in public beta, gives each conversation its own browser inside a LangSmith sandbox. When a login is needed, the agent hands the window to the user, so credentials stay out of model messages and traces. Handoff links expire after 15 minutes.

Subagents can now run asynchronously: set `"async": True` on the definition and they notify the parent when done, so it never sits in a polling loop.

The handoff pattern is the interesting part. It gives you a clean way to keep secrets out of the context window, which beats scrubbing traces afterwards.

**Try this:** pick one agent task that needs a login and route it through a handoff instead of a stored credential. Metric: whether any secret appears in your traces.

[Source](https://www.langchain.com/blog/managed-deep-agents-browser-use-and-asynchronous-subagents)

## 🔬 Amazon describes running agent sandboxes at 3.1 million a month
Sandman is Amazon's sandbox service for agentic reinforcement learning on shared Kubernetes. Each sandbox is a pod with a small daemon mounted into an unmodified task image. A scale test held 11,858 concurrent tiny sandboxes, and four production SWE-bench Verified training campaigns created 3.1 million sandboxes in October.

The paper, a 42-page preprint from 29 October, covers creation bursts, environment preparation and reclaiming abandoned sandboxes. The authors say they plan to open-source the daemon, provider and pool.

If you build coding agents, sandbox churn is a capacity problem of its own. Plan for bursts and for cleaning up sandboxes that nobody released.

[Source](https://arxiv.org/abs/2610.39711)

## ✍️ Nathan Lambert asks whether he was wrong about open models and cyber risk
After a wave of vulnerability disclosures he calls "Black October", Lambert revisits his earlier view that an open-weight Mythos would have been "fine". He concedes that calling the outcome "fine" undersold the turbulence, which he describes as "a forced industry update to a new way of working with software".

He still argues open models help balance offence and defence, and he says closed models "have played a very heavy part in the recent hacks".

His point for builders is practical: assume faster, cheaper vulnerability discovery whoever ships the model, and plan patch speed accordingly.

[Source](https://www.interconnects.ai/p/was-i-wrong-about-open-models-and)

## 🏗️ DoorDash moved most of its grocery-reorder agent offline
DoorDash cut grocery reorder latency from about 16 seconds to 2. An offline batch job asks an LLM to spot each customer's likely recurring purchases from 90 days of history, and deterministic checks validate the result before it's stored as reusable shopping-list data. At request time the app fetches that data and resolves each item against the current catalogue.

The agent still handles reasoning tasks, such as finding cheaper alternatives. Quantity changes and removals update the list directly, with no model call. Shopping-list views doubled and the flow's order rate rose by about 34%, per InfoQ.

Ask of every agent step whether it needs to be live. An offline job with validation is often cheaper and faster than a model call in the request path.

**Try this:** pick one agent flow with a predictable first step and precompute it. Baseline: current p50 latency. Metric: p50 latency and task success.

[Source](https://www.infoq.com/news/2026/10/doordash-ai-grocery-reorder/)
