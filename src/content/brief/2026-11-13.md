Most of today is about the keys and runtimes around the models, not the models themselves. Start with the one that might need a rotation before lunch.

## 🔥 A CI secret-stealer is going after AI-provider keys
Endor Labs reports a campaign that began on 10 November, using stolen credentials for real developers' GitHub accounts. A probe pull request tests write access, then a shell script pushed as a workflow or install hook steals CI secrets, escalates to cloud access and exfiltrates them. Endor counts more than 8,900 repos with payload evidence and at least 1,806 where credentials were exfiltrated, and says the stealer collects keys for OpenAI, Anthropic, Gemini, Hugging Face, Cursor and Copilot.

For an AI team, a CI secret is now often a model bill and a data path. Treat workflow files like production code, with short-lived credentials over stored keys.

**Affected:** Packagist `digitalelvis/neuronai-studio` 3.14.3 (malicious); Go `docker-env` v1.0.278 and v1.0.280; npm, PyPI and crates exposed through hijacked publisher accounts, with no confirmed malicious versions there yet · **Fixed in:** not stated by Endor; The Hacker News advises pinning `neuronai-studio` 3.14.2 or earlier · **Severity:** "Critical" (Endor) · **Stopgap:** code-owner review on workflow files, read-only default tokens, short-lived OIDC credentials, `npm ci --ignore-scripts` · **If compromised:** assume every reachable secret is exposed; rotate repo, cloud, registry and AI-provider keys, and remove cloud backdoors, since rotation alone is not enough
[Source](https://www.endorlabs.com/learn/github-actions-supply-chain-attack-targeting-ci-secrets-at-scale) · [The Hacker News](https://thehackernews.com/2026/11/4837-hijacked-github-accounts-ran-ci.html)

## 🚀 Gemini 4 Hydrogen is the cheap one
Google released Gemini 4 Hydrogen on 12 November, priced at $1.50 per million input tokens and $7.50 per million output tokens, flat across its 1M-token context. It's rolling out in the Gemini API and AI Studio, and Google cites 51 on the Artificial Analysis Intelligence Index against 50 for Gemini 4 Argon.

Flat pricing across a long context matters if your agents drag big transcripts around: the bill stops climbing with window size. The caveat is the usual one, that those benchmark figures are Google's.

**Try this:** run 20 of your own agent tasks on Hydrogen and on your current model. Compare cost per accepted result and pass rate.
[Source](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)

## 🤖 NVIDIA's Agent Substrate parks idle agents on warm pods
NVIDIA published Agent Substrate on 10 November, an open-source runtime for sandboxed agents, now in the CNCF Sandbox. It runs many sessions on a small pool of warm Kubernetes pods, checkpoints idle sessions (memory and filesystem) and restores them on any free worker. NVIDIA claims 10x the density of standard containers.

The design choice worth stealing is that an agent session stops being a pod. That makes cost track activity instead of session count, at the price of checkpoint and restore becoming part of your failure model. The project says its APIs are still changing, so it's a thing to read and prototype against, not to build on yet.
[Source](https://developer.nvidia.com/blog/agent-substrate-advancing-kubernetes-for-agents-at-scale/)

## 🔬 Train embeddings for the pooling you'll apply later
A Hugging Face post by Tom Aarsen on 11 November adds a training loss for multi-vector embeddings that is aware of token pooling. On a ModernBERT-base model trained on 120k MS MARCO triplets, pooling documents by a factor of 4 kept 97.8% of the unpooled score, against 94.6% for the ordinary loss, with 74.8% fewer document vectors.

If you pay for late-interaction storage, this is a cheap lever: the index shrinks by three quarters and the loss is smaller. It's a small-scale result on one model, so check it on your own corpus. Training and evaluation scripts and two checkpoints are released.
[Source](https://huggingface.co/blog/token-pooling)

## ✍️ One sentence changes how much Claude refactors
Simon Willison quoted Anthropic's prompting guide for Claude Fable 5.2 on 10 November. Telling the model it is the owner and long-term maintainer of the codebase raised consolidation of duplicated code from under 10% of runs to about 75%, in Anthropic's tests on small coding tasks.

The same guide says output tokens rose 70 to 80%, with unrequested changes such as new tests and docs, and the PR summary often missed small changes. So it's a dial, not a default: use it for cleanup work, and leave it out where changes should stay minimal.

**Try this:** run the same cleanup task twice, with and without the ownership sentence. Count diff size and unrequested changes.
[Source](https://simonwillison.net/2026/Nov/10/) · [Anthropic's guide](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2#say-who-owns-the-code)

## 🏗️ AgentCore's rebuilt runtime starts sessions in under 2 seconds
AWS announced on 12 November a next-generation Amazon Bedrock AgentCore runtime, available now. Sessions can use up to 8 vCPU and 32 GB, four times the previous version, container images can be 10 GB, and AWS says starts take under 2 seconds regardless of image size and concurrency. Idle agents scale to zero.

If cold starts really are that short, a lot of warm-pool machinery stops earning its keep, and big images become less of a design constraint. Per-session storage scoping is promised by re:Invent, so shared-storage designs should wait for it.
[Source](https://aws.amazon.com/blogs/machine-learning/run-agents-securely-and-efficiently-with-the-next-generation-agentcore-runtime/)

## ⚡ Also worth knowing
**🆕 New on the radar**
- **TPU Sync** — Google's Apache-2.0 library for moving KV cache between TPU memory, host DRAM and remote TPU nodes; the repo says APIs are evolving rapidly and publishes only nightly builds. Watch. [Source](https://github.com/google/tpu-sync)

**🛡️ Security & governance**
- **Apache HTTP Server 2.4.71** — fixes a critical mod_http2 remote code execution (CVE-2026-119618) found by Anthropic's scanner and Google; it affects 2.4.55 through 2.4.70, so upgrade if httpd fronts your inference or agent endpoints. [Source](https://httpd.apache.org/security/vulnerabilities_24.html)
- **LiteLLM proxy** — on deployments with an Azure model, a low-privilege user can read the proxy's environment variables, and on a typical deployment that exposes the master key (CVSS 7.7); fixed in 1.106.9, 1.108.6, 1.109.1 and 1.110.0-rc.2. [Source](https://github.com/BerriAI/litellm/security/advisories/GHSA-2rwg-2wh4-7c4f)
- **Notion and Fireworks AI** — Notion says chat transcripts sent to Fireworks were exposed, affecting fewer than 1% of workspaces, and recommends rotating any credentials pasted into Notion AI. [Source](https://notion.com/help/security-incident-involving-a-third-party-ai-vendor)
- **Chainstack breach** — the company says an attacker used the open-source ARTEX agent framework, entering through an internet-exposed Grafana with default admin credentials (disclosed 3 November, updated 10 November). [Source](https://chainstack.com/security-incident-nov-2026/)
- **llm 0.37.2** — Simon Willison's release fixes a bug where an OpenAI key could be sent to a different OpenAI-compatible provider; update if you route keys across providers. [Source](https://simonwillison.net/2026/Nov/11/llm/)

**🏢 Platforms & enterprise**
- **Google Cloud Organization Policy** — an MCP server and Gemini-written custom constraints are generally available as of 12 November, so agents can inspect and draft org policy. [Source](https://cloud.google.com/blog/products/identity-security/ai-powered-cloud-governance-whats-new-in-organization-policy/)

**🔬 Research**
