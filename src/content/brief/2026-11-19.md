Today's cheapest win is a version string: if vLLM is on your list of things that face other people's traffic, check it before you read anything else.

## 🔥 vLLM before 0.33.0 can be knocked over by unauthenticated requests
Two High advisories published on 18 November (CVSS v4 8.7 each) cover vLLM's OpenAI-compatible server. In one, a single request with many remote image URLs exhausts memory, CPU and connections, because there is no request-wide media budget. In the other, a server running with `--skip-tokenizer-init` is crashed by out-of-range token IDs sent to `/v1/completions`, `/v1/embeddings` or `/pooling`, taking every tenant down with it.

A third, Moderate advisory (CVSS v4 5.3) covers a model publisher's config leaking another checkpoint's tokenizer vocabulary through `/detokenize`. If an endpoint is shared between teams or customers, "unauthenticated" is the key word: put an authenticating gateway and a request-size cap in front, and don't count on the engine to do it.

**Affected:** vLLM 0.6.0 to before 0.33.0 (media budget); 0.28.0 to before 0.33.0 (token IDs, with `--skip-tokenizer-init`); before 0.33.0 (vocabulary leak) · **Fixed in:** 0.33.0 · **Severity:** High, CVSS v4 8.7 (two); Moderate, 5.3 (one) · **Stopgap:** not stated in the advisories · **If compromised:** not stated in the advisories
[Source](https://github.com/advisories/GHSA-cf32-wrp7-cjrw) · [Media-budget advisory](https://github.com/advisories/GHSA-rqcj-6434-qfch) · [Vocabulary-leak advisory](https://github.com/advisories/GHSA-9f95-xfwr-j77p) · [vLLM token-ID advisory](https://github.com/vllm-project/vllm/security/advisories/GHSA-q9v9-qpjp-fc24) · [vLLM media advisory](https://github.com/vllm-project/vllm/security/advisories/GHSA-5r3c-5x4v-8gjh)

## 🚀 Gemini 4 Neon: Google's mid-priced coding model, $3 in, $15 out
Google said on 18 November it was rolling out Gemini 4 Neon at $3 per million input tokens and $15 output, with cached input at $0.15 and a 1M-token context window. It's in the Gemini API through Google AI Studio on the paid tier, in Android Studio and in Antigravity for Pro and Ultra subscribers.

Google's own numbers put it at 61 on the Artificial Analysis Intelligence Index (third) and 58.6 on their Coding Agent Index (first). Those are vendor-presented scores, so read them as a reason to test, not a verdict. The part I'd care about is the cached-input price: if your agent loops reuse a long repository prefix, the 95% discount decides the bill more than the headline rate does.

**Try this:** replay 20 of your recent coding-agent tasks on Neon and on your current model. Track cost per successful task, not per token, since a cheaper model that retries more can cost more.
[Source](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)

## 🤖 Coral: an open gateway where agents write code, not tool calls
Coral, an open-source gateway that surfaced on Show HN on 16 November, sits between agents and the systems they touch. The agent sends a short TypeScript program; Coral runs it in a V8 isolate with no network access and no credentials, checks every tool call against workspace policy (allow, ask or block, with optional human approval), and only then adds credentials and forwards the call.

The design choice worth stealing is that secrets never enter the agent's execution environment, so a prompt-injected program has nothing to exfiltrate. The cost is another hop to operate: a shared server needs an OIDC identity provider and a TLS reverse proxy, and Coral's enterprise tier (single sign-on, user provisioning, audit log) is listed as coming soon. It's Apache 2.0 with about 5,000 GitHub stars.
[Source](https://github.com/withcoral/coral)

## 🔬 Small LoRA RL runs lifted Nemotron 3.5 Super on coding and agent benchmarks
A preprint submitted on 17 November trains Nemotron 3.5 Super (120B total, 12B active) with reinforcement learning on five expert-built task sets, one at a time. Each run uses a fresh rank-32 LoRA adapter and the CISPO algorithm on Tinker, with no supervised stage. The authors report gains of 4.5 to 13.8 points across 12 headline benchmarks, for example Terminal-Bench 2.1 from 63.9 to 70.3 and AutomationBench from 14.8 to 27.5.

For architects, the interesting part is the unit of work: one small adapter per task family means you can ship, version and roll back a specialisation without touching the base weights. The abstract page links no code or weights yet, so treat the numbers as the authors' own until someone reproduces them.
[Source](https://arxiv.org/abs/2611.22161)

## ✍️ Cloudflare says most steps don't need an LLM
In a write-up of Michelle Chen's talk at the AI Engineer Code Summit (published 17 November), Cloudflare calls itself a "neolab" and says it is building "System One" models: small, fast ones, so "we don't have to send every request to an LLM." Its first, Clairic, launched last month as an extraction model that returns typed values from unstructured input in a single forward pass. A second, Clef, is a decision model that Cloudflare says took about two weeks to build.

The argument is about failure modes: an autoregressive LLM can hallucinate or return malformed JSON, while a single-pass extractor has a fixed output shape. If your pipeline calls a frontier model to fill a schema, that step is a candidate to replace. The write-up gives no benchmarks, so measure on your own documents first.
[Source](https://latent.space/p/cloudflare/)

## 🏗️ Datadog lets you A/B a model swap on live agent traffic
Datadog added Online Experiments to Agent Observability, announced around 17 November: you split live traffic between a control and a variant, score responses with agent evaluators, and compare latency, tokens, cost and errors, with feature flags setting the split. In Datadog's own example the newer of two models cost an estimated 44.3% less, with quality scores of 3.84 against 3.86 on a 1-to-5 scale.

The example is useful mostly for what it hides. The newer model supplied invalid tool parameters more often, and that wasn't visible in the overall quality score; confidence intervals for duration and workflow errors were too broad to call a regression. So wire tool-call validity in as its own metric before trusting an average score.
[Source](https://www.infoq.com/news/2026/11/datadog-ai-agent-observability/)
