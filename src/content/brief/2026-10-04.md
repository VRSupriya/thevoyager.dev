Sunday's feeds were thin, which is a good excuse to look at plumbing. Most of what's worth reading today is about what happens around the model: disclosure windows, gateways, evals and spending limits.

## 🔥 Agents are shrinking the gap between a security fix and a working exploit
InfoQ reports that maintainers are watching public clues turn into attacks fast. Anil Madhavapeddy, who works on the OCaml compiler, saw probes matching a bug pattern in server logs minutes after the fix PR opened. rclone's Nick Craig-Wood described handling over 40 security disclosures in one month, against roughly 20 a year in the project's first decade.

If your release process depends on a quiet embargo while the patch sits in a public repo, assume that window is now minutes. The mitigations discussed point at architecture: short-lived credentials and protocol-level revocation, so a vulnerable operation can be switched off remotely without waiting for everyone to upgrade.
[Source](https://www.infoq.com/news/2026/10/open-source-ai-security/)

## 🚀 GPT-6.1 Sol is the cheap option for coding and computer use
Per InfoQ's DevDay recap, OpenAI describes GPT-6.1 Sol as an update to GPT-6 Sol aimed at coding, computer use and professional tasks. It's priced at one-fifth of GPT-6 Astra's standard rates, with cached input at $0.10 per million tokens. A Decisions API is also in limited preview, using the Luna model for classification and routing.

The price gap is the interesting part: it makes Sol a plausible default for agent loops, with Astra kept for the hard steps. I'd test that on your own tasks before trusting it, since the page doesn't give benchmarks and this is the vendor's framing.
[Source](https://www.infoq.com/news/2026/10/openai-devday-2026/)

## 🤖 Istio gets an MCP-aware waypoint, and a deadline to go with it
Istio 1.31 can run agentgateway, a Rust data plane that speaks MCP alongside HTTP, as the L7 waypoint in ambient mesh. There's also a canary waypoint annotation that sends a configurable share of new in-mesh connections to a new waypoint without client changes.

For anyone routing agent tool traffic, this puts authorization and rate limits for MCP in the same mesh policy path as everything else, instead of a separate gateway. Separately, the project is leaving Google Cloud for release artifacts: the first scream test is October 13, and the final one is December 8–9. If your clusters pull from gcr.io/istio-release, put that on a calendar.
[Source](https://www.infoq.com/news/2026/10/istio-1-31-agentgateway/)

## 🔬 "Pass@1" hides how often agents get the same task wrong on a rerun
Microsoft's ThinkingBox on Hugging Face runs 507 stateful business tasks 20 times each and grades the final database state, not the agent's story. Claude Opus 5.5 hits 67.16% pass@1 but passes all 20 attempts on only 241 tasks (47.53%). Of 79,853 failed trials, 67.24% ended cleanly with valid tool calls and still failed the state check, mostly on wrong field values.

That is the failure you can't catch with a tool-call trace. The tasks are synthetic and the numbers are the authors', so check how close the workflows are to yours. The environment is MIT-licensed, which makes a rerun on your own stack realistic.
[Source](https://huggingface.co/blog/microsoft/thinkingbox)

## ✍️ Simon Willison wants hard budget caps on by default
Willison's argument: coding agents make it trivial to deploy something that calls paid APIs, and an email alert doesn't help when a bug burns thousands overnight. He proposes services that stop at the limit by default, with an explicit opt-out. He notes AWS launched spending limits in September and Google Cloud added Spend Caps in July.

Worth treating as a design requirement for any agent you let provision things: a per-run budget enforced outside the agent, not inside its prompt.
[Source](https://simonwillison.net/2026/Oct/3/default-hard-budget-caps/)

## 🏗️ DoorDash's GenAI platform is mostly gateways
In a QCon AI talk summarized by InfoQ, DoorDash describes an LLM gateway across providers with cost attribution, an agent gateway handling auth, rate limits and tool discovery for 50+ internal MCP servers (about 300,000 tool calls a day), and an evals platform. Moving some workloads to self-hosted open-weights models via Modal cut costs, in some cases "20x" by their account.

The pattern to borrow is owning the surfaces that are specific to your company (auth, cost visibility, observability) while buying or swapping the rest. Treat the 20x as one team's number.
[Source](https://www.infoq.com/presentations/doordash-genai-platform-architecture/)
